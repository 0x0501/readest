## 上游带来的主要功能

- **阅读与批注：** Notebook 关联写作空间、跨 PDF 页选字与复制时合并断行、放大 PDF 时锁定横向平移、双栏翻页在书脊处铰接、封面与图片全屏查看、轻点隐藏图片查看器控件；可自定义页眉页脚、键盘/鼠标快捷键及回流书籍缩放字体。参见上游 #5928、#5831、#6030、#6107、#5907、#6183。
- **导入与外部服务：** 内置网页浏览器剪藏、已登录网页和需账号的网络小说导入、小说章节选择；ReadEra 书签/高亮/进度导入，Notion 笔记与高亮同步，BookOrbit 手动同步；Audiobookshelf 有声书伴读与纯电子书流式阅读。参见 #5870、#6119、#6032、#5949、#6034、#5856、#6056。
- **同步与朗读：** 登录前选择是否启用 Readest Cloud（已接入本 fork 的 Better Auth 登录页）、按字段时间戳合并分组、防止删除墓碑被旧笔记覆盖、云端缺失封面恢复；朗读播放器逐句显示、跳过日文括号内读音，网页版接受 Apple Enhanced/Premium 声音。参见 #6045、#5911、#5818、#5908、#6057、#6099。
- **外观与平台：** 书库和阅读器分别设置主题/颜色、所有平台可用的电子墨水屏模式、Nearby BookDrop 配对/提示音/重连、Linux CEF 与 Nix 构建；前端升级到 Tailwind CSS 4 / daisyUI 5。参见 #5948、#6113、#6023、#6074、#6083、#5884。上游版本已到 0.12.8，后续还含 2026-09-12 的图片查看器改进。

上游 [0.12.8 发布说明](https://github.com/readest/readest/releases/tag/v0.12.8) 汇总了这段时间的用户可见更新；以上是自本地旧基线以来的功能归类，不表示所有平台安装包都在本机打包实测。

## 本 fork 的合并取舍

- 继续保留 Drizzle + Better Auth、自托管域名与部署配置；上游 Stripe/IAP、旧 Supabase 登录组件、官方社区/遥测入口没有复活。移除了随上游进入但在这里没有任何调用者的 `BillingIntervalToggle`。
- 上游 R2 阅读统计归档（#5835）依赖整套 Supabase 压缩/恢复/账号清理路由，本 fork 暂不移植这些路由和 Cron/R2 绑定。现有 `stat_pages` 热数据同步照常工作，且写入改用迁移 020 的显式用户 RPC；但历史行会持续增长。若该表规模成为负担，再把归档任务完整移植到 Drizzle，不可只打开定时器。上游的 020/021 SQL 仍照常纳入迁移链。
- 33 份冲突翻译目录按 JSON 键集合合并，再由 i18n 扫描器去除本 fork 不使用的键；新增的格鲁吉亚语目录补齐了 23 条本 fork 专属文案。
- 接入上游 019–022 四条 SQL；`local_006` 把 020 新增的 `auth.users` 外键重指向 Better Auth 用户表；`local_007` 由 Better Auth 迁移编译器生成，为 JWKS 添加 `alg`/`crv`。`foliate-js` 子模块从旧指针前移到上游的 `9e05bf2`。个人 CI 的 pnpm action 对齐上游 v6.1.0，Node 仍为 24。
